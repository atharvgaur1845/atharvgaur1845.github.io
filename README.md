## Usage

### Local Development
Simply open `index.html` in a web browser. All files are self-contained with no external dependencies.

```bash
# Navigate to the directory
cd atharvgaur.github.io

# Open in default browser (macOS)
open index.html

# Or on Linux
firefox index.html
```

### Deployment
1. **GitHub Pages**: Push to `gh-pages` branch or set as source in repository settings
2. **Static Hosting**: Deploy to any static hosting service (Vercel, Netlify, AWS S3, etc.)
3. **Traditional Server**: Copy files to web server directory

## Navigation

- **Home**: Return to main page from any section
- **Back Links**: Each content page has a "← Back to Home" link
