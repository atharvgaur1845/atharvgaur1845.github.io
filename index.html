  Featured Projects

Deepfake Detection using CNN-LSTM
Technologies: PyTorch, OpenCV, ResNet-18, Bi-LSTM
Achievement: 87.69% accuracy, AUC-ROC ≈ 0.90

Built a hybrid deep learning model combining ResNet-18 CNN for spatial feature extraction and Bidirectional LSTM for temporal pattern analysis across 16-frame video sequences. Implemented comprehensive face preprocessing with landmark alignment and data augmentation, achieving robust balanced generalization with balanced F1 scores on both real and fake classes.

Automated Lunar Traverse Planner
Technologies: Python, NumPy, Matplotlib, YOLO crater detection
Achievement: LAM Challenge 2025 Finalist (Top 0.3%)

Developed an intelligent path planning system for lunar rover missions integrating YOLO-based crater detection with solar illumination-aware navigation. Implemented solar shadow simulation using physics-based shadow polygons and designed hierarchical three-tier navigation with science-optimal waypoint selection and automated regolith sampling site identification.

BDH Narrative Consistency Evaluator
Technologies: PyTorch, Transformers, Mechanistic Interpretability

Built inference and interpretability pipeline on Baby Dragon Hatchling (BDH) transformer architecture for narrative contradiction detection. Engineered structured training data through synthetic contradiction generation and implemented mechanistic interpretability probes for high-resolution attention visualization across transformer layers and heads.

Image Segmentation using U-Net
Technologies: PyTorch, Albumentations

Implemented complete semantic segmentation pipeline with U-Net architecture, custom DataLoader with train/validation splits, and real-time augmentations. Applied Dice + BCE hybrid loss function and integrated GPU acceleration with reproducible seeding for scalable experimentation.

Micromouse Maze Solver
Technologies: C++, Teensy 4.1, VL53L0X, IMU — IEEE BITS Pilani

Designed autonomous micromouse robot with embedded systems integration using Teensy 4.1 MCU, VL53L0X ToF sensors, and IMU for precise navigation. Implemented flood fill algorithm, PID control for lane-centering, and shortest-path logic for real-time maze solving.
